# Mini logiciel de gestion d'une station spatiale

## Auteur
Frédéric Gobfert

## Objectif
L’objectif final pourrait être de gérer une station, son équipage, ses ressources, ses modules et différentes missions, avec sauvegarde et tests automatisés.

## Remarques
Ce projet est un projet d'apprentissage Python réalisé avec l'aide de l'IA.
