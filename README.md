# Mini logiciel de gestion d'une station spatiale

## Auteur
Frédéric Gobfert

## Status
En cours de réalisation.

## Objectif
L’objectif final pourrait être de gérer une station, son équipage, ses ressources, ses modules et différentes missions, avec sauvegarde et tests automatisés.

## Remarques
Ce projet est un projet d'apprentissage Python.

### Concepts travaillés
- architecture de projet ;
- fonctions ;
- classes ;
- composition entre objets ;
- dictionnaires et listes ;
- exceptions ;
- annotations de types ;
- __str__ / __repr__ ;
- tests unitaires ;
- parametrize ;
- tests d’état ;
- fichiers ;
- JSON ;
- sérialisation / désérialisation ;
- @classmethod.
